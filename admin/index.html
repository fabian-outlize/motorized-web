Zum Anmelden brauchst du einen GitHub-Token mit Schreibrechten auf dieses Repository. Der Token bleibt in diesem Browser und wird nirgends sonst gespeichert. 



    

      Wie komme ich zu einem Token?
      
    
        
  1. Auf github.com/settings/personal-access-tokens gehen.
    2. 
        
  2. Generate new token → Fine-grained.
    3. 
        
  3. Bei Repository access nur dieses eine Repository auswählen.
    4. 
        
  4. Bei Permissions → Repository permissions den Punkt
            Contents auf Read and write stellen.
    5. 
        
  5. Token erzeugen, kopieren und hier einfügen.
    6. 
      

      
Setz beim Token ein Ablaufdatum. Läuft er ab, erzeugst du einfach einen neuen.
